# LoreCue 前端体验样机

这是 LoreCue 的可点击前端体验样机，包含创作工作台、“我的团”、主持人咨询台、场次档案、资料库和全局 AI 助手。
当前用于验证信息组织、操作流程与视觉效果，不连接数据库或真实 AI。

## 可以体验什么

- 小说、影视剧本、跑团模组与世界观项目首页
- 按创作类型建立新项目，并自动获得相应的章节、场次、线索或条目结构
- 项目、内容创作、故事结构、设定资料、视觉媒体、检查管理六个分级领域
- 正文、大纲、故事树、故事节点、二维图、双层时间线与版本快照
- 角色档案中的动机、人物弧、说话方式、知情范围与披露条件
- 人物关系图、地点地图、组织阵营、物件线索与世界观设定
- 跑团模组专属的主持人真相、场景节点、线索网络、NPC 知情、地图遭遇、结局和玩家手册
- 文档树全文搜索、新建文档、章节正文编辑与浏览器自动保存
- 文档复制、跨分组移动、可撤销归档和归档内容筛选
- 整个创作项目可导出带格式版本与项目身份的 JSON 备份
- Markdown 快捷工具、专注写作、阅读预览、页面宽度与字数统计
- 文内查找替换、草稿状态、叙述视角、地点和故事时间元数据
- 单篇 Markdown 导出，便于在浏览器草稿之外留存副本
- AI 修改先显示原文与建议差异，由作者明确接受或保留原文
- 右侧写作检查栏可从 Markdown 标题生成大纲，并分别查看检查、引用和私有备注
- 检查结果标明检测方式、正文依据和设定依据，不把相似性判断冒充事实
- 一致性与疑似重复提醒
- 人物关系、线索触点和故事发生顺序与叙述顺序对照
- 从项目已引用资料中插入地图、立绘或 BGM 引用
- 比较与恢复历史版本，恢复前先保护当前内容
- 多个 D&D、CoC、CoJ、无限团项目的首页、筛选和搜索
- 新建团时也可选择系统无关或自定义规则
- 区分规则系统、剧本模板、实际团项目与场次档案
- 同一个剧本模板可以建立互不串线的不同团项目
- 新建团项目草稿并分别填写剧本模板与团名
- 五种情况：明确答案、合理推断、临场新编、泄密风险、团后确认
- 三种咨询强度：严格依据、最小补全、救场优先
- 区分“原文明确”“合理推断”“暂无依据”
- 区分“原文摘录”“AI 拟词”“AI 新编”
- 把复制与实际采用分开
- 将实际说出或发生的临场内容送入团后归档台
- 手动 BGM 建议，不监听对话，也不自动切歌
- 场次列表、团前简报、本场目标和使用资料快照
- 按时间记录剧本事实、玩家行动、主持人陈述与临场新编
- 团后逐条决定口胡是长期事实、NPC 主张、仅本场还是废弃
- 为下一次团保留承接信息
- 统一管理人物、地点、地图、立绘、BGM、规则和文档
- 资料只有被项目明确引用后才进入对应 AI 检索范围
- AI 助手提供查设定、创作协作、冲突检查与 GM 救场入口
- AI 回答同时展示原文依据、合理推断和 AI 新编，不会自动写回正文或设定

## 原型边界

首页包含多个演示创作与团项目，创作深度交互集中在“潮汐来信”，带团深度交互集中在
“萨菲港旧案 · 老友组”。正文草稿会自动保存在当前浏览器的本地存储中；其他编辑、创建、导入和
AI 仍以界面效果为主，不会写入真实项目文件、数据库或调用真实模型。更换浏览器、清理站点数据或
更换设备后，浏览器草稿不会自动迁移。
它不接入语音、QQ 群聊或跑团平台，不会自动判断玩家正在说什么，也不会直接替主持人向玩家发言。

## 最简单的启动方式

Windows 可以直接双击项目根目录中的：

```text
start_lorecue.cmd
```

也可以运行 Python 版本：

```text
start_lorecue.py
```

两个入口都会寻找可用的 Node.js 与 pnpm、启动样机，并打开
`http://localhost:3000/`。保持启动窗口开启即可继续体验；按 `Ctrl+C`
会停止完整的本地服务进程树并释放 3000 端口。

## 手动启动

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
```

验证构建与关键页面内容：

```bash
pnpm test
pnpm exec eslint app tests
```
