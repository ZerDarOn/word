# LoreCue 主持人咨询台原型

这是 LoreCue 的第一版可点击验证原型。它聚焦跑团现场的一个窄问题：
主持人卡住时主动输入问题，系统如何在不冒充原剧本、不泄露全知信息的前提下快速给出可用建议。

## 可以体验什么

- 五种情况：明确答案、合理推断、临场新编、泄密风险、团后确认
- 三种咨询强度：严格依据、最小补全、救场优先
- 区分“原文明确”“合理推断”“暂无依据”
- 区分“原文摘录”“AI 拟词”“AI 新编”
- 把复制与实际采用分开
- 将实际说出或发生的临场内容送入团后归档台
- 手动 BGM 建议，不监听对话，也不自动切歌

## 原型边界

当前数据全部为“萨菲港旧案”的演示内容；输入框不会真正调用 AI，记录也只保存在当前页面状态中。
它不接入语音、QQ 群聊或跑团平台，不会自动判断玩家正在说什么，也不会直接替主持人向玩家发言。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
```

验证构建与关键页面内容：

```bash
pnpm test
pnpm exec eslint app tests
```
